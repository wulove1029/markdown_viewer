# 閱讀工作台：第一批升級交付

日期：2026-09-07。基於 1.29.0 的本機開發版；未發布、未變更版號。

## 已實作

- 主工具列以文字選單切換閱讀、Markdown、並排預覽與 Office；保留原有快捷鍵和未儲存內容保護。已在 source 編輯中的模式切換維持文件物件、游標與選取。
- 柔和亮色／深灰藍暗色、統一 Qt／預覽／Office Auto 主題色，修正側欄暗色箭頭；長檔名不再推擠模式控制。
- 外觀偏好新增舒適／寬版／滿版行寬，以及三段行距。作用於 Markdown 預覽（含並排），使用者 CSS 仍有優先權。Office 自有排版與 PDF 不受行寬設定影響。
- 首頁提供開啟、最近文件、快速開啟。操作只在空白工作台生效；內部保留網址會被攔截，不發出外部導航。
- 第二次啟動延後載入主視窗與文件模組；IPC 以 EOF 收齊 UTF-8 路徑，不在 GUI 執行緒 waitForReadyRead。保留舊客戶端相容性、超時與長度限制。
- 文件樹以約 6 ms 工作片段建立 detached subtree，再掛入畫面；取消新舊掃描、完成後重播選取及保留展開／捲動。
- Markdown body 快取採 LRU、32 筆與估算內容 64 MiB 上限，key 包含完整路徑、mtime、大小、ctime、inode；不快取讀取期間變動的檔案。舊預覽在取得 parser lock 後再次檢查取消，避免無效解析。
- PDF 頁面尺寸加入記憶體快取：最多 8 份、合計 50,000 頁，不存密碼。每次仍先由 QPdfDocument 驗證／載入文件，避免快取繞過解密。
- 文件標籤不變時不寫索引，移除或內容改變時仍正常保存。

## 試用方式

保留整個 `dist/reading-upgrade/MarkdownViewer` 資料夾，執行其中 `MarkdownViewer.exe`；若已有舊版執行中，先正常關閉，否則單一實例機制會把開檔轉交舊版。

建議依序：開一份 Markdown → 切換 Markdown／並排並確認游標 → 外觀設定改行寬／行距 → 切亮暗 → 開 PDF 再切回 → 關閉重開確認閱讀位置。用文件副本檢查外部修改與未儲存提示。

回退：關閉試用版，執行原安裝版即可；新增閱讀設定為額外 key，未修改文件格式。若要回退程式碼，只處理本次 diff，不覆蓋其他工作。
