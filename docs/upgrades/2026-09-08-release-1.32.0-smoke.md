→ `<scratchpad>\smoke-3mb.md`（3,145,728 bytes）。

```powershell

$p = Start-Process -FilePath dist\MarkdownViewer\MarkdownViewer.exe `
     -ArgumentList "<scratchpad>\smoke-3mb.md" -PassThru `
     -RedirectStandardError smoke2.err -RedirectStandardOutput smoke2.out
Start-Sleep 6; Get-CimInstance Win32_Process -Filter "Name='MarkdownViewer.exe'"
```
