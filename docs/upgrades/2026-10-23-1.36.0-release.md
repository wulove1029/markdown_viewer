# Markdown Viewer 1.36.0

## Improvements

- Streamlined workspace, focus mode, pinned tabs, command search and clearer save state.
- Reading presets, warm paper color, chapter navigation, image zoom and source excerpts.
- Recoverable drafts, templates, writing outline, selection statistics and source/preview synchronization.
- Incremental library search, bounded caches and background loading for large documents.
- Large code previews retain complete text while restoring syntax highlighting near the viewport. Repeated highlighted lines share one payload entry.
- Export from unsaved source snapshots, annotation recovery and safer interrupted file relocation.
