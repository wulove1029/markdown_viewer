# 本輪後仍開放的工作

本表與 [本輪驗證紀錄](2026-09-21-optimization-progress.md) 一起閱讀；不是把未驗證或未達標項目視為完成。

| 範圍 | 現況與後續驗收 |
|---|---|
| C1 啟動門檻 | lazy split preview 已實作；MainWindow 合成量測 375.23 → 357.32 ms，僅改善 4.77%，未達 15%／150ms。需要真實冷啟動分段量測，不能以 import main 代替 |
| C3 冷高亮 | warm 100KB code 150.91 → 18.22ms；冷 cache 142.79ms，未達冷開 <80ms。需 profiling lexer/tokenizer，不重寫輸出語意 |
| C5／E11 資源 | Mermaid／PlantUML 實際有用途；22 組 CodeMirror 主題切換未請求 highlight CSS，但未證明所有輸出路徑皆不需要，保留資源 |
| C6 語系裁剪 | 單獨 locale 精簡減少 42.07MiB，未達原 100MB 目標。E7 乾淨依賴封裝另減 357.06MiB，兩者效果須分開說明；完整實體安裝仍需補驗 |
| C7 UPX | 維持停用；未取得 UPX + 防毒／SmartScreen 的完整驗證證據 |
| C8 歷史產物 | 指定五個 dist 子目錄的刪除遭工具自動審核政策拒絕，全部保留；不以其他工具繞過 |
| 交易崩潰復原（D6-8） | `file_ops.py` 有準備／原件暫存與同程序回滾，但無 durable manifest／啟動回放。後續需強制終止程序、重開後驗證原件與sidecar一致 |
| PDF 冷開（D6-5） | 仍一次取得全部頁面尺寸，後續需對大頁數 PDF 設計首屏分批且保留閱讀頁碼／縮放 |
| PDF 快照（D6-1） | 複製可見 viewport 像素；整頁高解析度／向量輸出須另設計，不冒稱現有快照具備 |
| 資料安全重構（E6） | `_on_browser_paths_migrated` 等複雜方法本輪不重構；先補草稿、dirty tab、回滾、外部競爭等分支測試 |
| 甘特圖刪除相依 | 新增任務不重用已被引用的 ID；刪除任務仍可能留下使用者原本的 `after` 參照，未自動改寫排程，後續應提供明確提示／選擇 |
| 實體桌面驗證（D6-6） | offscreen／自動測試不等於實體安裝、高 DPI、多螢幕與 SmartScreen 人工驗收；依下方步驟補驗 |
| 其餘 D6 選配 | PDF 本文編輯／簽名、i18n、雲端同步、外掛、未命名草稿、可取消大附件、列印大綱等維持需求池，本輪未擴充 |

實體桌面補驗：在可回復測試機安裝發布的 installer，分別以 125%／150%／200% 與雙螢幕移動主視窗；開 Markdown／Office／PDF，確認模式選單、Properties、標籤／圖譜、PDF 卡片與匯出對話框可見且可操作；保存範例文件、關閉所有視窗後重開，核對分頁／閱讀頁碼與檔案內容。記錄 Windows 版本、縮放、安裝／啟動退出碼及截圖。
