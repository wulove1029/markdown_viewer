# Bundled Markdown editor

This directory contains the offline Vditor fork shipped by **Office Viewer
4.2.0** (`cweijan.vscode-office`). It is used to provide the Office Viewer
Markdown Editor toolbar, outline, themes, find/replace, block handles, and
CodeMirror code-block controls without a network dependency.

This is not an unmodified build of upstream Vditor `master`: Office Viewer is
based on Vditor, but its pinned fork adds the editor/theme/code-block behavior
that the application intentionally targets.

Office Viewer source: https://github.com/cweijan/vscode-office

Upstream Vditor: https://github.com/Vanessa219/vditor
